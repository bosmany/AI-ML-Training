Ch 8: Linear Algebra for ML

Compiled from the chapter text on 2026-09-29. A study aid: the lesson has the explanations and the caveats.

In short

  • Data is vectors and matrices. One sample = a vector. A dataset = a matrix, shape (samples, features).
  • NumPy arrays do math elementwise — completely different from Python lists with the same operators.
  • Dot product (np.dot or @) = elementwise multiply then sum, and geometrically = |a||b|cos(θ) — the core of a neuron, a linear model prediction, and cosine similarity.
  • Norms (np.linalg.norm) measure length; the norm of a difference is distance — the basis of KNN. L1's unit ball has corners (sparsity); L2's is smooth (shrinkage).
  • Matrix multiplication (X @ w) computes predictions for an entire dataset in one vectorized operation — this is literally what model.predict() does.
  • Transpose (.T) swaps rows/columns to make shapes compatible; identity (np.eye) is the matrix "1".
  • Eigenvectors are directions a matrix only scales, never rotates. PCA is exactly "find the eigenvectors of the covariance matrix" — the directions of maximum variance.
  • Regularization penalizes a weight vector's norm during training. L2 (Ridge) shrinks weights smoothly; L1 (Lasso) drives some weights to exactly zero.

Key ideas by section

Why Linear Algebra? Data IS Vectors and Matrices

  • A whole dataset — many samples, each with the same features — is a matrix: one row per sample, one column per feature.
  • We'll use NumPy from here on — the library that makes vectors and matrices fast and convenient.
  • In linear algebra, that's called a vector.

Vectors: NumPy Arrays vs Python Lists

  • A NumPy array looks like a list but behaves completely differently for math: operators act elementwise, not like list concatenation or repetition.

The Dot Product: The Single Most Important Operation in ML

  • Two facts fall straight out of this formula: if the vectors point the same direction (θ ≈ 0°), cos(θ) ≈ 1 and the dot product is as large and positive as it can be.
  • If they're perpendicular (θ = 90°), cos(θ) = 0 and the dot product is exactly zero — the vectors share nothing.
  • There's also a geometric one, and it explains something the algebra alone doesn't: why similarity and dot products are related.

Vector Norms: Measuring Length and Distance

  • The L2 norm (Euclidean length) of a vector is sqrt(sum(v**2)) — the straight-line distance from the origin.
  • The distance BETWEEN two points is just the norm of their difference — this is exactly how algorithms like K-Nearest-Neighbors decide who's "close."
  • Now the practical use of distance: K-Nearest-Neighbors doesn't have a training phase at all — to classify or predict for a new point, it just measures the distance (usually the L2 norm of the difference) from that point to every other point, and looks at whichever k are closest.

Matrices: Shape and Indexing

  • A matrix is a 2D array. .shape tells you (rows, columns) — for a dataset, that's (samples, features).

Matrix Multiplication: Computing an Entire Batch at Once

  • Matrix multiplication (@) is what lets you run the dot-product "neuron" from 8.3 across EVERY sample in a dataset in one operation, instead of writing a loop.
  • For A @ B to work, A's number of columns must equal B's number of rows: (m, n) @ (n, p) → (m, p).
  • Let's prove that with the real dataset. sklearn.linear_model.LinearRegression doesn't do anything mysterious to make a prediction — it fits a weight vector w and a bias b during .fit(), then .predict() is exactly X @ w + b, the same expression you just wrote by hand.

Transpose and the Identity Matrix

  • The identity matrix (np.eye(n)) is the matrix equivalent of the number 1 — multiplying by it changes nothing.
  • The transpose (.T) flips a matrix's rows and columns — needed constantly to make shapes line up for multiplication.

Eigenvectors and PCA Intuition

  • A matrix isn't just a table of numbers — applying it (multiplying a vector by it) is a transformation: it can rotate, stretch, or squash a vector.
  • An eigenvector is the rare, special exception: a vector whose direction the matrix doesn't change — the matrix only stretches or shrinks it, by a factor called its eigenvalue.
  • Sorting eigenvectors by eigenvalue (largest first) gives you PCA's "principal components" — the best directions to keep if you must compress the data into fewer dimensions.

L1 vs L2 Regularization, on a Real Linear Model

  • Back in 8.4 you saw the L1 and L2 norms and their unit balls. Regularization is where that geometry stops being abstract: instead of just minimizing prediction error, a regularized model minimizes error + λ · ||w|| — error PLUS a penalty on how large the weight vector is.
  • Which norm you penalize changes the result in a very specific, predictable way.

Watch out

  • One real wrinkle if you experiment further: an eigenvector's sign is not unique — v and -v are both valid eigenvectors for the same eigenvalue.
