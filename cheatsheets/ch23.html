Ch 23: Convolutional Neural Networks

Compiled from the chapter text on 2026-09-21. A study aid: the lesson has the explanations and the caveats.

In short

  • A convolution slides a small, shared filter across an image, giving far fewer parameters than a fully-connected layer and reusing the same learned pattern at every position.
  • Padding controls whether the output shrinks; stride controls how far the kernel jumps each step (larger stride = smaller output).
  • Max pooling downsamples a feature map by keeping only the strongest activation in each window.
  • Channels in = image channels (1 grayscale, 3 RGB); channels out = number of learned filters, which feeds the next layer's in_channels.
  • The classic CNN shape: (Conv2d → ReLU → MaxPool2d) × N → Flatten → Linear layers for classification.

Key ideas by section

Why Not Just Flatten the Image?

  • But that single layer already has 784 × 128 + 128 = 100,480 parameters — for a tiny image and a modest hidden size — and every one of those weights is learned independently per pixel position.
  • A convolution fixes this by using a small filter with shared weights that slides across the whole image.
  • Nothing stops you from flattening a 28×28 grayscale image into a 784-number vector and feeding it to nn.Linear(784, 128) like Chapter 22.

The Convolution Operation: Kernels & Feature Maps

  • A kernel (or filter) is a small grid of learnable weights — commonly 3×3 or 5×5.
  • Repeating this at every position produces a feature map — an image-shaped grid of "how strongly does this pattern appear here?" scores.
  • Convolution slides that kernel across the image, and at every position it does an element-wise multiply between the kernel and the patch of image underneath it, then sums the results into a single number.

Padding & Stride

  • The output size formula: out = floor((in + 2*padding - kernel_size) / stride) + 1.

Channels: RGB In, Feature Maps Out

  • Its out_channels is a design choice — the number of different filters you want the layer to learn, which becomes a stack of out_channels feature maps.
  • The first Conv2d's in_channels must match the image's channel count.
  • Every subsequent layer's in_channels must match the previous layer's out_channels.
