Ch 14: Data Visualization

Compiled from the chapter text on 2026-09-30. A study aid: the lesson has the explanations and the caveats.

In short

  • plt.bar() compares categories. plt.hist()/box plot show a distribution's shape and spread. plt.scatter() shows the relationship between two variables. Count plot is a bar chart for raw category frequency.
  • Seaborn (sns.barplot, sns.boxplot, sns.countplot, sns.heatmap) works directly on DataFrames and aggregates automatically.
  • plt.subplots(rows, cols) builds a grid of charts in one figure — the standard shape of a real EDA report.
  • Real EDA workflow: profile shape/dtypes/missingness first, then univariate → bivariate/multivariate → correlation heatmap (with its limits) → class balance → time patterns.
  • Match the chart to the question (14.13), and know the 5 ways a technically-correct chart still misleads (14.14) — including never claiming causation from a correlation chart.
  • ML diagnostics: learning curves (over/underfit shape), residual plots + error distributions (patterned vs. random errors), confusion matrices (essential under class imbalance), and feature importance (real, but never causal).
  • That's Module 3 — you can load, clean, visualize, AND diagnose a model on any tabular dataset. Next: Module 4, where you build the models themselves.

Key ideas by section

Why Visualize? Numbers Hide, Charts Reveal

  • Four datasets can share the exact same mean, variance, and correlation — and look completely different when plotted (this is a real, famous example called Anscombe's Quartet).
  • Summary statistics compress data; visualization shows you what got compressed away.
  • This chapter's exercises all print text facts too (so they're checkable exactly like every other chapter), but the whole point is the chart below each one — look at it.

Bar Charts: Comparing Categories

  • A bar chart compares a numeric value across discrete categories. plt.bar(categories, values) is the whole API — add plt.xlabel(), plt.ylabel(), and plt.title() so the chart is self-explanatory without you standing next to it.

Scatter Plots: Do Two Things Move Together?

  • A scatter plot puts one variable on each axis and plots every (x, y) pair as a point — the visual companion to Chapter 9's correlation coefficient.
  • A tight diagonal line of points means high correlation; a shapeless cloud means little to none.

Seaborn: Statistical Plots, Less Code

  • Seaborn is built on top of Matplotlib and works directly with DataFrames — sns.barplot(data=df, x='col1', y='col2') automatically groups and aggregates for you. sns.boxplot() shows the median, quartiles, and outliers of each…

Subplots: Multiple Charts, One Figure

  • plt.subplots(rows, cols) creates a GRID of charts in one figure — an "EDA story" is almost always several small charts side by side, not one giant chart.
  • It returns a figure and an array of axes; call chart methods on each axes[i] instead of on plt directly.

Systematic EDA: Shape, Types, Missingness, Target

  • The running examples for the rest of this chapter are Chapter 12's real orders.csv/customers.csv and Chapter 13's deliberately messy employees_messy.csv — no new dataset needed.
  • Before drawing a single chart, profile the dataset the same way Chapter 13 did: shape, dtypes, and missingness.

Univariate Analysis: Numerical vs Categorical

  • For categorical columns, a count plot (sns.countplot) is a bar chart pandas builds the counting step into automatically.
  • A histogram (14.3) shows a numeric distribution's overall SHAPE; a box plot summarizes it in five numbers (min, Q1, median, Q3, max) and makes outliers and skew easy to spot at a glance across MANY groups at once — which a histogram can't do side by side nearly as compactly.

Bivariate and Multivariate Relationships

  • Bivariate = two variables at once (a grouped box plot, a scatter plot). Multivariate = three or more — usually by encoding a third variable as color, size, or a separate panel, since a chart only has two spatial axes.

Correlation Matrices, Heatmaps, and Their Limits

  • A correlation heatmap shows every pairwise correlation between numeric columns at once, color-coded — a fast way to scan many relationships together instead of building one scatter plot per pair.

Class Balance and Imbalance

  • Before building any classifier, look at how balanced its TARGET actually is — a severely imbalanced target changes which metrics you can trust (more in 14.16) and whether a plain bar chart of counts is even readable.

Time-Based Patterns

  • A line chart over time reveals trend and seasonality that a bar/histogram can't, because it's the only chart type where the x-axis position itself carries meaning (chronological order) rather than just category identity.

Misleading Charts: How They're Made, and How to Catch Them

  • The same data can be shown honestly or deceptively — often with a change of just one parameter.

ML Diagnostics I: Learning Curves & Residual Plots

  • A learning curve plots training-set score and validation-set score as training data grows.
  • A residual plot (predicted vs. residual = actual − predicted) diagnoses a DIFFERENT thing: whether the model's errors are patternless (good) or systematically wrong in some region (a sign the model is missing real structure).

ML Diagnostics II: Confusion Matrices & Prediction-Error Distributions

  • For a CLASSIFICATION model, a confusion matrix is the residual plot's counterpart — and it matters most exactly when 14.11's class imbalance is severe, since a single accuracy number actively hides the failure.

ML Diagnostics III: Feature Importance and Its Limitations

  • A feature importance plot ranks which inputs the model relied on most.
  • For a tree-based model like RandomForestClassifier, .feature_importances_ measures how much each feature reduced impurity across all its trees.
