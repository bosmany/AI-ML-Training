Ch 1: Python Basics

Compiled from the chapter text on 2026-09-21. A study aid: the lesson has the explanations and the caveats.

In short

  • Programs and running (1.1): a program is a list of instructions the Python interpreter follows top to bottom, exactly as written.
  • Your workbench (1.2): use the ▶ Run button, edit code in the console and re-run with Ctrl+Enter, use print to see values, and write # comments.
  • Variables (1.3): a variable is a name attached to a value, like a sticky note. You can reassign it, give one value two names, and follow snake_case naming.
  • Types (1.4): int, float, str and bool. You know why 5 and '5' behave differently.
  • Error messages (1.5): read from the bottom up, and tell NameError, SyntaxError, TypeError and ZeroDivisionError apart.
  • Type conversion (1.6): int(), float(), str(), bool(). Data from files is text; int('3.9') fails, so go through float first.
  • Operators (1.7): // for full batches, % for the remainder, ** for squares and roots, comparisons for True/False. You wrote MSE and RMSE from scratch.
  • Number pitfalls (1.8): floats are approximate, / gives a float, and int(), // and round() treat fractions differently.
  • Strings up close (1.9): indexing from 0, negative indexes, slices [start:stop:step], and immutability.
  • String tools (1.10): .strip(), .lower(), .replace(), .split(), .join(), raw strings r'...' and triple quotes.
  • F-strings (1.11): f'Loss: {loss:.4f}', {:03d} for zero-padding, {:.2%} for percentages, and {:,} for thousands separators.
  • Getting unstuck (1.12): read the last line, go to the line number, print values and types, change one thing at a time.

Key ideas by section

What Is a Program? What Is Python?

  • That written-down job is a program: a list of instructions that a computer follows one after another, exactly as written.
  • Ours is Python, created by Guido van Rossum and first released in 1991.
  • Code has to be written in a programming language, a strict, small vocabulary with fixed grammar rules.

Your Workbench: The Run Button, the Console, print, and Comments

  • Look at the top bar: a chip says Loading Python... the first time (about ten seconds) and then Python Ready.
  • When you press it, the code is copied into the console, the dark panel with the >>> prompt, and executed.
  • Click in it, change something, and press Run ▶ or Ctrl+Enter to run your edited version. Clear empties the output area.

Variables: Names Stuck on Values

  • That is exactly what a variable is: a name attached to a value.
  • The picture to keep in your head is a sticky note.
  • She is training her cat-versus-dog model, and today it guessed 412 of 500 photos correctly.

Types: Why 5 and "5" Are Not the Same Thing

  • The difference is the quotes, and understanding why is the most important idea in this chapter.
  • Every value in Python has a type: the kind of thing it is.
  • She writes the digit 5 the same way both times, and gets two different answers.

Reading Your First Error Messages

  • An error message is Python's honest report of what it could not do.
  • Every programmer sees it every day, and the beginners who progress fastest are the ones who learn to read it instead of fearing it.
  • One more rule: an error stops the program right there.

Type Conversion: Turning Text into Numbers (and Back)

  • This is also a TypeError, but the message differs from the one in section 1.5, because now the text is on the left: can only concatenate str (not "int") to str. Concatenate is the technical word for gluing text.
  • Four conversion functions do this, and each is named after its target type: int(x), float(x), str(x) and bool(x).
  • The cure is to convert the value: build a new value of the type you need.

Operators: Doing Maths and Making Comparisons

  • An operator is a symbol that tells Python to combine or compare values, and the values it works on are called operands.
  • Asha's dataset has 1000 photos, and her training code feeds them to the model in small groups called batches of 32 photos at a time (like dealing cards a handful at a time instead of all at once).
  • In 7 + 2, the plus is the operator and 7 and 2 are the operands.

Integer and Float Pitfalls: Why 0.1 + 0.2 Is Not 0.3

  • First, never test floats for exact equality with ==.
  • Computers store decimals in binary (ones and zeros).
  • abs() gives the size of a number without its sign (abs(-0.2) is 0.2), so abs(a - b) is "how far apart are they, ignoring direction".

Strings Up Close: Indexing, Slicing and Immutability

  • A string is a row of characters (letters, digits, spaces and symbols), and every character sits in a numbered seat, like seats in a cinema row.
  • The one strange rule is that the numbering starts at 0, not 1.
  • The number of a seat is called its index.

String Tools: Cleaning, Splitting, Joining

  • split() cuts a string into pieces and gives you a list of them.
  • A tool that belongs to a value is called a method.
  • Labels arrive with stray spaces, odd capitals and extra punctuation, and a model treats 'Cat', 'cat ' and 'CAT' as three different things.

F-strings: Putting Values into Sentences

  • There is a better tool: the f-string (the "f" stands for formatted).
  • There are many quotes and plus signs to get right, a missed space is easy to make, and the loss prints with eight digits, which is far too many for a log.
  • (4) The same with epoch: the number is converted to text automatically.

How to Get Unstuck

  • The technique is debugging by printing: show the intermediate pieces, and compare each one with what you expected.
  • It is the normal working state, and there is a skill to getting out of it.
  • Every programmer, on every project, spends a large share of the day stuck.
