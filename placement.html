Placement

Find your starting point

An adaptive test across six domains that skips what you already know and points you at the right learning path. It gets harder while you answer correctly and easier when you miss, and it stops early when it is confident.

What to expect

≤ 35multiple-choice questions, about 6 per domain, levels 1 to 5
3optional coding tasks graded by real Python in your browser
15 mintypical time; no timer, no penalty for skipping a question

Domains: Python core, OOP and design, data structures and algorithms, web / APIs / HTTP, DevOps / Linux / Docker / CI, data and ML basics. You start each domain at level 2; two correct answers in a row move you up a level, a miss moves you down. Answers are revealed only at the end, with an explanation for each one. Do not look things up: an honest result gives you a better path.

Coding tasks (optional)

Three short functions, graded by hidden assertions that run in real Python (Pyodide 0.26.4) inside your browser. Each one counts for 25% of its domain score (Python core, data structures and algorithms, data and ML basics). Skipping leaves those scores based on the questions alone.

Coding tasks

Write each function, press Run. The first run downloads the Python runtime (about 10 MB, cached afterwards). Your code is graded only by pressing Run; you can run as often as you like and the last run counts. A run that takes longer than 8 seconds is stopped.
